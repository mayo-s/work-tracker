Components

    Component gallery

    The UI elements of the Work Tracker (SPEC 5.5), each with its use and the HTML to copy. Not linked in the navigation.

    Colors

    Use the variables, never hex values. Warning colors only for real warnings; mint only for positive values.

    Text

    Inter, regular and semibold. Muted text for secondary information such as weekday, target or notes.

    Title

    Section heading

    Body text with emphasis, a link and muted text.

    Values

    Times and durations always with num (tabular digits). Overtime and balance: negative as warning, positive in mint, zero plain.

    +1:15 -8:00 0:00 08:15–16:00

    Badges

    Short labels: day types, counts, balance. A warning badge for things that need attention.

    PTO Balance 12:30 3 to review

    Buttons

    One primary button per area (e.g. Save); everything else normal. Links that act like buttons use button class.

    Link as button

    Form fields

    Label above the field. Invalid fields get aria-invalid="true" and a warning message below.

    End is before start

    Tables

    Durations right-aligned with td class="num"; clock times stay left-aligned with a span class="num". Row states: is-today, is-warning (e.g. a past work day without entries), is-weekend.
